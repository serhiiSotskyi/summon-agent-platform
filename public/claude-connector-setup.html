Claude Organization Connector

Summon setup for Claude and Cowork

This page is for the Claude Primary Owner or Owner who will add Summon as an organization custom connector. The connector is already deployed. Each team member authorizes with their own Summon account, so Claude uses that member's workspace access and role permissions.

Connector URL

https://summon-agent-platform.vercel.app/api/mcp

Leave advanced OAuth client fields blank unless Claude explicitly requires them. Summon supports OAuth discovery and dynamic client registration.

Admin setup

  1. Open Claude as an Owner or Primary Owner.
  2. Go to Organization settings, then Connectors.
  3. Add a custom connector. Choose the Web or remote MCP option.
  4. Name it Summon.
  5. Paste the connector URL above.
  6. Save the connector for the organization.

If the custom connector option is not visible, check that the user is an Owner or Primary Owner and that custom connectors are enabled for the Claude organization.

Member connection

  1. Open Claude or Cowork.
  2. Open Customize, then Connectors.
  3. Find Summon and select Connect.
  4. Sign into Summon with the member's own account.
  5. Authorize Claude to use Summon.

Use Summon to list my agents.

Controlled write test

Use Summon to create a test agent named "Claude Connector Smoke Test" in my default workspace. Keep it inactive or paused.

Expected behavior

  • Claude should ask the member to authorize Summon before tool use.
  • Tool calls should use the authorized member's Summon account.
  • The default workspace should come from that member's Summon memberships.
  • Members can only perform actions allowed by their Summon role.
  • Risky external changes remain approval-gated by Summon.

Support note

If setup fails, capture the exact Claude screen and error message. The most useful checks are whether the user is an Owner or Primary Owner, whether custom connectors are enabled, and whether Claude is using the connector URL exactly as shown above.
