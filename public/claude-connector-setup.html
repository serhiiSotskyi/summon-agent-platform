Claude Organization Plugin

Agent Platform setup for Claude and Cowork

This page is for the Claude Primary Owner or Owner who will add the Agent Platform plugin for the team. The plugin lets Claude/Cowork turn recurring work into shared Agent Platform automations, run tests, review results, and manage approvals. Each team member authorizes with their own Agent Platform account, so Claude uses that member's workspace access and role permissions.

Recommended setup

  1. Open Claude as an Owner or Primary Owner.
  2. Go to Organization settings, then Plugins.
  3. Add plugins and choose Upload a file.
  4. Upload the Agent Platform plugin ZIP.
  5. Set the plugin to Installed by default or Available for install.
  6. Ask one team member to connect and run the smoke tests below.
https://summon-agent-platform.vercel.app/agent-platform-claude-plugin.zip

Manual upload is the quickest Monday test. For ongoing updates, use Claude's GitHub-synced plugin marketplace with the repository that contains .claude-plugin/marketplace.json.

What the plugin does

  • Exposes an Agent Platform plugin inside Claude/Cowork.
  • Provides workflows such as /automate-task, /review-automation-results, and /improve-automation.
  • Teaches Claude to ask only the missing setup questions.
  • Creates shared draft automations from recurring-task briefs.
  • Runs manual tests before schedule activation.
  • Returns links to automations, run results, artifacts, and approvals.

Connector engine

https://summon-agent-platform.vercel.app/api/mcp

This remote MCP connector is bundled in the plugin. Add it manually only if plugin upload is blocked in Claude admin settings. Leave advanced OAuth client fields blank unless Claude explicitly requires them.

Fallback connector setup

  1. Open Claude as an Owner or Primary Owner.
  2. Go to Organization settings, then Connectors.
  3. Add a custom connector. Choose the Web or remote MCP option.
  4. Name it Agent Platform.
  5. Paste the connector URL above.
  6. Save the connector for the organization.

If the custom connector option is not visible, check that the user is an Owner or Primary Owner and that custom connectors are enabled for the Claude organization.

Member connection

  1. Open Claude or Cowork.
  2. Open Customize, then Plugins.
  3. Install or enable Agent Platform if it is not installed automatically.
  4. When Claude asks to connect Agent Platform, sign in with the member's own account.
  5. Authorize Claude to use Agent Platform.

Smoke tests

Automation setup test

/automate-task Create a daily automation that checks our shared reporting notes and tells the team what needs attention. Ask me what details you need before setting it up.

Context test

Use Agent Platform to show my context and default workspace.

Agent list test

Use Agent Platform to list my automations.

Results review test

/review-automation-results Show me recent Agent Platform automation results and anything that needs approval.

Expected behavior

  • Claude should ask the member to authorize Agent Platform before tool use.
  • Tool calls should use the authorized member's Agent Platform account.
  • The default workspace should come from that member's Agent Platform memberships.
  • Members can only perform actions allowed by their workspace role.
  • Risky external changes remain approval-gated by Agent Platform.
  • New recurring tasks should be created as draft automations, tested, then activated only after review.

Support note

If setup fails, capture the exact Claude screen and error message. The most useful checks are whether the user is an Owner or Primary Owner, whether Plugins/Cowork/Skills are enabled for the Claude organization, and whether Claude can reach the public connector URL.
